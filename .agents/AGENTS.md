# Aturan Manajemen Cabang Git
- JANGAN pernah melakukan merge dari branch `develop` ke `main` secara otomatis.
- Hanya lakukan merge ke `main` jika pengguna meminta secara eksplisit.
- Secara bawaan, commit dan push hanya ditujukan untuk branch tempat Anda bekerja (biasanya `develop`).
